### Policy

Publish only from a clean main checkout after the root release gates pass.
The root, canonical catalog, and legacy compatibility tags are one atomic,
immutable tag set at the same commit. This migration record and its tests do
not create tags. If publication occurs on another UTC date or after another
release on 2026-07-27, update this record and consumer pins in a reviewed
commit before running mage tag.

applications/catalog/v0.*. Each wrapper references the canonical machine,

### Application local

Application-local test identities and chatbot-mesh workload identities were
migrated atomically with every repository consumer. They have historical
aliases in this record but no runtime wrapper because they are not reusable
catalog paths.
